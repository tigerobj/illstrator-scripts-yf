======================
使用jsx

## 新增腳本

- `GenerateWhiteCompoundFromSelection.jsx`（建議使用這個英文檔名，GitHub 比較容易搜尋）
  - 功能：選取來源圖形（可用紅色十字），隨機產生白色圖形，最後合併成複合路徑。
- `紅色物件隨機產生白色複合路徑.jsx`
  - 與上面英文檔名內容相同，保留中文版本方便本機辨識。

## 使用方式

1. 在 Illustrator 先選取來源物件。
2. 執行 `GenerateWhiteCompoundFromSelection.jsx`。
3. 依序輸入：
   - 產生數量
   - 最小縮放%
   - 最大縮放%
4. 腳本會產生白色圖形並建立複合路徑。
