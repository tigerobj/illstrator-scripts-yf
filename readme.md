======================
使用jsx

## 新增腳本

- `GenerateWhiteCompoundFromSelection.jsx`（建議使用這個英文檔名，GitHub 比較容易搜尋）
  - 功能：用「一個紅色 X 來源物件」，透過數學方程式生成多組白色 X 圖案，最後合併成複合路徑。
- `紅色物件隨機產生白色複合路徑.jsx`
  - 與上面英文檔名內容相同，保留中文版本方便本機辨識。

## 使用方式

1. 在 Illustrator 先選取來源紅色 X（一個就可以）。
2. 執行 `GenerateWhiteCompoundFromSelection.jsx`。
3. 依序輸入：
   - 圖案數量（群組數）
   - 每個圖案最小半徑（格數）
   - 每個圖案最大半徑（格數）
   - X 間距倍率
   - 圖案中心分散倍率
   - 抖動比例
4. 腳本會用數學方程式（superellipse / diamond / rose / lemniscate / ring）生成由白色 X 排列的圖，並建立複合路徑。


- 補充：目前輸出會維持來源 X 的原始角度，不會再隨機旋轉成「十字 +」。

- 補充：已調整方程式與預設參數，讓輸出風格更接近你提供的「2」那種多個小型白色 X 群組。

- 補充：已移除會產生外圍零散點的尾巴邏輯，並加入孤立點過濾，減少圖案外側散落。

- 補充：已加入缺口補齊（gap closing）邏輯，減少圖形少一兩個 X 的不協調情況。

- 模式更新：現在會「自動執行 20 次」，每次先生成 1 個群組，再各自轉成 1 個複合路徑，所以最終會得到 20 個複合路徑物件；其餘參數全自動亂數，不再跳出輸入框。

- 新增記錄檔機制：會在 `我的文件/ai_white_x_shape_log.txt` 記錄已生成形狀簽名；下次執行會先讀取，避免再次產生相同形狀。

## Python 參數調整工具

- `x_pattern_param_tuner.py`
  - 提供 GUI（滑桿 + 可編輯輸入框）調整以下參數：
    - 每個圖案最小半徑（格數）
    - 每個圖案最大半徑（格數）
    - X 間距倍率
    - 圖案中心分散倍率
    - 抖動比例
  - 按「產生圖形」即可顯示預覽，方便核對數值。
  - 執行：`python x_pattern_param_tuner.py`

- JSX 模式更新：圖案數量（群組數）固定為 1，改用 GUI（滑桿 + 文字方塊）輸入 5 個參數，按「產生圖形」才執行，並加入輸入防呆檢查。
